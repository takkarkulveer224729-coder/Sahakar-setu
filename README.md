# COOP FARIDKOT – Sahkar Setu KCC Mobile Portal

SOL 0301 is Head Office/Admin. SOL 0302–0325 are branch logins.
Branches upload completed KCC mobile-number forms. Head Office can view all submissions and branch status.

For production: set a strong SECRET_KEY and individual PASS_0301 ... PASS_0325 environment variables before first database initialization.
